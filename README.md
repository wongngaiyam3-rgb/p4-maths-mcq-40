# 小四數學40題

ivan’s learning-explorer · 2026–2027

依據上載數學習作的課題範圍另行編寫40道四選一題目：乘法10題、除法10題、整除性6題、四邊形6題、分割與拼砌4題、一筆畫4題。幾何圖以SVG呈現。

學生選擇4A–4C、1–25號，自動記錄作答進度；同一裝置及身分可續做。完成全部題目並提交後，由伺服器評分，答案鎖定，再顯示解說。重做會保留歷次紀錄。

教師入口：`teacher.html`。伺服器核對密碼並發出8小時會話；支援班別、學號、狀態篩選，75人名冊、歷次作答、逐題答案及CSV匯出。

## 資料處理

班別及學號是學生自報資料，並非身分驗證。不收集姓名。每次作答以隨機256位元能力憑證保護，憑證只存於該裝置；學年及應用範圍分開。學習資料和答案匙位於Supabase，並非GitHub。所有資料表啟用RLS並拒絕瀏覽器直接讀寫，只有經校驗的Edge Function可存取。教師密碼以PBKDF2雜湊儲存，沒有放入公開原始碼。錯誤登入設15分鐘速率限制。網絡中斷時保留本機待同步答案並明確顯示狀態。

`edge-function.ts`為伺服器原始碼；部署時使用Supabase提供的伺服器環境變數，不可把服務密鑰加入此儲存庫。`questions.json`不包含答案或解說。
